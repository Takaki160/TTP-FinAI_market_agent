# AI-Powered Market Intelligence

## 项目概述

本项目旨在开发一个AI驱动的分析层，整合实时市场数据、行业走势和隔夜新闻。
系统利用大语言模型（LLM），将叙述性的市场色彩（Market Color）转化为交易员、风险管理者和量化分析师可使用的量化洞察。

## 技术架构

系统采用模块化架构，包含以下组件：

* **LLM提供方**：通过Google AI Studio利用Gemini大模型进行推理和总结。
* **工作流编排**：使用LangChain/LangGraph管理复杂的分析流程。
* **数据接入**：实施模型上下文协议（MCP），标准化AI与各类数据源（包括市场数据、新闻和持仓数据）之间的通信。
* **用户界面**：用于交互和聚合洞察可视化的聊天机器人UI。
